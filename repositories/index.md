## MolSpin

**[MolSpin](https://molspin.eu)** is an open-source, general-purpose framework for molecular spin dynamics. I am the project's **lead developer and innovator**, maintaining and extending the code base and developing new theoretical and numerical functionality.

MolSpin is designed as a virtual spin-dynamics laboratory rather than as a program restricted to a single type of calculation. Its extensible architecture supports general spin systems and a range of propagation and analysis strategies for quantum-spin dynamics.

Current development areas include:

- general time-independent and time-dependent spin Hamiltonians;
- coherent and open-system spin dynamics;
- relaxation and dephasing models;
- stochastic Schrödinger-equation approaches;
- large-spin-system algorithms and performance improvements;
- magnetic-resonance and spin-chemistry observables;
- reusable operator and pulse descriptions for modern spin-dynamics workflows.

**Links:** [MolSpin website](https://molspin.eu) · [MolSpin on GitHub](https://github.com/MolSpin-Group/MolSpin)

## Related computational projects

My broader software work includes algorithm development for electronic-structure calculations, biomolecular multiscale modelling and analysis of complex molecular trajectories. I have also contributed to collaborative software projects such as the **Automated Ligand Searcher (ALISE)** and to computational workflows that connect molecular simulation with spin-dynamics observables.

Only public and released software is linked here; active private research code is intentionally not exposed on this website.
