Visual comparison · one Hamiltonian, different approximations

What is simplified, and what is retained?

Hartree–Fock

One optimized antisymmetric determinant. Exact exchange for that determinant, but no dynamical correlation beyond its mean field.

Kohn–Sham DFT

A noninteracting reference reproduces the density with an exact functional in principle; practical predictions depend on the approximate exchange–correlation functional.

Post-HF correlation

Excitations correct the single-reference description; MP2, CI and coupled cluster include them in mathematically different ways.

CASSCF / multireference

Several configurations contribute to each electronic root. CASSCF optimizes active orbitals and configuration coefficients; state averaging optimizes one orbital set for selected roots.

These are conceptual schematics, not electron-density plots or an ordering of universal accuracy. A basis set and an electron-correlation method are separate choices.
