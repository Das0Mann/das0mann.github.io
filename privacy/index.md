## Website contact

This academic website is maintained by **Luca Gerhards**. Questions about data processing on this site can be directed to [luca.gerhards@uni-oldenburg.de](mailto:luca.gerhards@uni-oldenburg.de).

## Hosting and technical requests

The pages are served by **GitHub Pages**, a static website hosting service operated by GitHub. When a browser requests a page or asset, its network connection necessarily discloses technical request data, such as its IP address, to the hosting infrastructure. For the provider's practices, see the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Optional website analytics

This site uses **Google Analytics 4** (measurement ID `G-RNH61RX63Z`) only after the visitor selects **Allow analytics** in the consent panel. The Google Analytics script is not requested before affirmative consent. If analytics is rejected, the site continues to function normally.

If consent is granted, Google may receive page-view and technical browser information and may store first-party analytics cookies. The implementation disables Google advertising-related signals and requests IP anonymization. The site owner does not use these data to make automated decisions about individual visitors.

Consent can be changed using **Privacy settings** in the footer. Rejecting analytics or withdrawing consent disables subsequent tracking requests and attempts to delete this site's accessible Google Analytics cookies. Withdrawal does not retroactively erase information already transmitted to Google.

Your choice and its timestamp are stored locally in your browser under `qc-analytics-consent-v1` for no more than **180 days**. This strictly functional record is used to remember your preference; it is not an analytics identifier.

For information about Google's processing practices, see [Google's Privacy Policy](https://policies.google.com/privacy).

## Mathematics and visual materials

The website uses system fonts instead of requesting Google Fonts. Interactive lecture simulations, navigation and image previews run locally in the browser. On pages containing mathematical notation, the site loads a version-pinned MathJax library from the Cloudflare cdnjs network, which necessarily receives a technical network request when that resource is loaded. MathJax is used to display equations, not for behavioral advertising.
